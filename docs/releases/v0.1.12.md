# Dev Cockpit 0.1.12

这版是稳定性修复版，重点解决“运行中命令被端口检测误判”的交互问题，并补充对应回归测试。

## Highlights

- 当前命令由 Dev Cockpit 托管运行时，命令按钮会稳定显示为运行中，并保持可停止。
- 运行中的命令不会再被外部端口检测覆盖成“已在线”或“需清理”。
- 补充回归测试，确保托管运行态优先级高于端口复用和残留端口判断。
- 保持现有核心功能不变：项目扫描、命令运行、日志、端口状态、Python/Conda 环境诊断、设置页和更新检查。

## Verification

- `pnpm release:check`
- CLI fixture scan
- CLI doctor
- 隔离临时 Node 项目启动、识别端点、停止进程模拟
- 浏览器检查项目页和设置页：无横向溢出、无乱码占位、无错误横幅

## Upgrade

```bash
npx local-dev-cockpit@latest
```

桌面版建议下载 `Dev-Cockpit-Setup-0.1.12-win-x64.exe` 覆盖安装。
