# Dev Cockpit 0.2.0

0.2.0 新增 API Lens 第一版，把 Dev Cockpit 从“项目恢复工作台”扩展到“本地接口观察”。

## Highlights

- 新增左侧一级菜单 `接口 / API Lens`。
- 支持添加本地目标服务，例如 `http://127.0.0.1:8000`。
- 生成本地代理地址 `/lens/:targetId/*`，用于观察前后端请求。
- 记录最近请求的方法、路径、状态码、耗时、错误、请求摘要和响应摘要。
- 支持按目标服务、方法、状态和关键词筛选请求。
- 支持把单条接口请求一键复制为 AI 上下文。

## Security

- 只允许代理 `http/https`。
- 默认只允许 `localhost`、`127.0.0.1`、`::1` 和局域网私有地址。
- 自动脱敏 `authorization`、`cookie`、`set-cookie`、`x-api-key`。
- 自动脱敏 body 中的 `password`、`token`、`secret`、`authorization`、`cookie` 等字段。
- 请求记录只保存在内存 ring buffer，每个目标最多 200 条，不落盘。
- 单次请求 body 超过 10MB 会返回 413，文件上传和大请求暂不观察。

## Verification

- `pnpm --filter @local-dev-cockpit/server test`
- `pnpm --filter @local-dev-cockpit/web test`
- `pnpm release:check`
- 本地启动测试 HTTP 服务，并通过 `/lens/:targetId/hello` 验证请求转发和记录展示。

桌面版建议下载 `Dev-Cockpit-Setup-0.2.0-win-x64.exe` 覆盖安装。
