# Dev Cockpit 0.1.4

这是一次品牌一致性版本，重点把 Dev Pilot 首屏体验延伸到桌面应用图标和发布资产。

## Highlights

- 新增 Dev Pilot 风格桌面图标：雷达圆环、控制台轨迹和项目节点视觉统一到 Windows exe/安装包。
- 新增可复现图标生成脚本 `pnpm desktop:icon`，避免桌面图标成为不可维护的二进制黑盒。
- 保留 0.1.3 的 Dev Pilot 首屏欢迎弹窗、Anime.js 入场动画和应用内更新检查。
- 版本推进到 `0.1.4`，应用内 `/api/health` 和 `/api/update` 使用新版本号。

## Windows Desktop

推荐下载 `Dev-Cockpit-Setup-0.1.4-win-x64.exe`。它是标准安装向导，适合日常使用；已安装旧版本时会直接覆盖升级。

如果只想临时试用，可以下载 `Dev-Cockpit-0.1.4-win-x64.exe`。portable 用户需要关闭旧 exe 后手动替换新文件。

当前产物仍未代码签名，Windows 可能提示未知发布者。

## Verification

- `pnpm desktop:icon`
- `pnpm release:check`
- `pnpm --filter @local-dev-cockpit/desktop dist:win`
- 启动 portable exe 后验证 `/api/health` 返回 `0.1.4`
