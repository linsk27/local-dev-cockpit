# Dev Cockpit 0.1.8

这版继续收紧 Python/Conda 项目的运行体验，重点解决桌面版无法继承终端环境时的配置成本。

## Highlights

- Python 项目的“运行环境”区域会按需读取 `conda env list --json`。
- 本机 Conda 环境会显示为候选按钮，例如 `Conda: api-env`，点击即可填入对应 `python.exe`。
- 候选环境检测只在打开单个项目的运行环境区时执行，不参与后台扫描和项目列表轮询。
- 手动保存 Python 环境时继续做轻量校验，错误路径和异常 Conda 名称不会写入配置。
- 修复 0.1.7 release note 的编码乱码，后续 GitHub Release 文案保持 UTF-8。

## 使用建议

普通 Python 项目优先保留项目内 `.venv`、`.conda`、`environment.yml` 或 `.vscode/settings.json`。如果项目依赖只在某个全局 Conda 环境里，打开项目详情的“运行环境”，选择检测到的 Conda 候选后保存即可。

## Windows Desktop

推荐下载 `Dev-Cockpit-Setup-0.1.8-win-x64.exe`。它是标准安装向导，适合日常使用；已安装旧版本时会直接覆盖升级。

如果只想临时试用，可以下载 `Dev-Cockpit-0.1.8-win-x64.exe`。portable 用户需要关闭旧 exe 后手动替换新文件。

当前产物仍未代码签名，Windows 可能提示未知发布者。
