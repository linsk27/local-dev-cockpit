# Dev Cockpit 0.1.11

这版是稳定性收口版本，重点不是加新模块，而是让真实项目更容易被识别、排查和启动。

## Highlights

- Python 后端入口识别更完整：支持 `app.py`、`main.py`、`app/main.py`、`src/app/main.py`、`server.py`、`api.py` 等常见结构。
- Flask 项目会生成 `python -m flask --app ... run --host 127.0.0.1 --port 5000`，FastAPI 项目继续生成 `python -m uvicorn ... --host 127.0.0.1 --port 8000`。
- Web 面板中“未识别到命令”的项目会按类型给出下一步，不再只显示空状态。
- CLI `doctor <项目路径>` 也会给出同样的无命令原因提示，方便别人电脑上用终端排查。
- README 和 roadmap 明确稳定版策略：侧栏暂时只保留“项目”和“设置”，新模块后置。

## When A Project Has No Commands

- Node：检查 `package.json` 是否有 `dev` / `start` scripts，或是否选错了仓库根目录。
- Python：检查是否有 `manage.py`、`app.py`、`main.py`、`app/main.py`、`src/app/main.py` 等后端入口。
- Docker：检查是否有 `docker-compose.yml` 或 `compose.yml`。
- 仓库外壳：优先选择 `frontend`、`backend`、`apps`、`packages`、`services` 等子目录。
