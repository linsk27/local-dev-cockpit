# Dev Cockpit 0.2.6

This release refines Resource Radar workflows and continues the server/core architecture cleanup started in 0.2.5.

## Highlights

- Resource Radar now uses modal flows for adding, importing, and exporting resources, keeping the main toolbar compact.
- Resource export supports scoped exports for all resources, current filters, selected item, status, or category.
- The resource page now separates filtering, capture, selection, actions, and export state into focused composables.
- Shared API contracts and runtime schemas now live in `@local-dev-cockpit/core`.
- Server route handling is split by feature area, with static serving, port listening, native shell actions, update checks, and JSON persistence isolated behind services.
- JSON writes use shared atomic write helpers and file-operation queues, with a versioned migration entry point for future local data changes.
- Added text-encoding and Playwright visual smoke checks for release validation.
