# Dev Cockpit 0.1.6

这版修复两个真实下载试用问题：更新检查不再暴露底层 `fetch failed`，Python 后端会识别编辑器里选择的 Conda/venv 解释器。

## Highlights

- Python 启动前会读取项目或父级工作区的 `.vscode/settings.json`。
- 支持 `python.defaultInterpreterPath` 和旧版 `python.pythonPath`。
- 支持绝对路径、`${workspaceFolder}`、`${env:VAR}`、`%VAR%` 和 `~`，可直接指向 `python.exe`，也可指向环境目录。
- 如果 VS Code/Cursor 已经为项目选择了全局 Conda 环境，Dev Cockpit 会优先使用该解释器，而不是回退系统 Python。
- 更新检查失败时改为可读提示：网络、代理、证书、GitHub API 限流等情况不会再显示原始 `fetch failed`。

## Windows Desktop

推荐下载 `Dev-Cockpit-Setup-0.1.6-win-x64.exe`。它是标准安装向导，适合日常使用；已安装旧版本时会直接覆盖升级。

如果只想临时试用，可以下载 `Dev-Cockpit-0.1.6-win-x64.exe`。portable 用户需要关闭旧 exe 后手动替换新文件。

当前产物仍未代码签名，Windows 可能提示未知发布者。
