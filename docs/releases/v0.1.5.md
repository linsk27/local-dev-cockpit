# Dev Cockpit 0.1.5

这版重点补强真实项目的运行环境选择，尤其是 Python 后端项目。目标是让别人下载后更少遇到“终端能跑，Dev Cockpit 一点就缺包”的情况。

## Highlights

- Python 命令现在会优先使用项目或父级工作区里的 `.venv`、`venv`、`.env`、`env`、`.conda`、`conda`。
- 支持 Conda `environment.yml` / `environment.yaml`，会通过 `conda run -n <env> python ...` 运行。
- 新增 uv / Poetry / Pipenv 环境入口识别：`uv.lock`、`poetry.lock`、`[tool.poetry]`、`Pipfile`。
- 扫描器兼容带 UTF-8 BOM 的 `package.json` / `composer.json`，减少 Windows 写文件后项目漏扫。
- 命令区继续在启动前标记“缺环境 / 需确认”，服务端也会拦截必定失败的硬运行时缺失。

## Windows Desktop

推荐下载 `Dev-Cockpit-Setup-0.1.5-win-x64.exe`。它是标准安装向导，适合日常使用；已安装旧版本时会直接覆盖升级。

如果只想临时试用，可以下载 `Dev-Cockpit-0.1.5-win-x64.exe`。portable 用户需要关闭旧 exe 后手动替换新文件。

当前产物仍未代码签名，Windows 可能提示未知发布者。
