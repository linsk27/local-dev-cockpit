# Dev Cockpit 0.1.3

这是一次桌面安装与更新体验版本，重点补齐普通 Windows 用户预期的安装向导、升级入口和应用内更新提示。

## Highlights

- 新增标准 Windows Setup 安装包：支持安装向导、选择安装路径、桌面快捷方式和覆盖升级。
- 保留 portable 免安装版，适合临时试用或不想写入安装目录的场景。
- 设置页新增“应用更新”，可以手动检查 GitHub Release 并下载安装包。
- 发现新版本时，左上角品牌区会出现闪烁下载图标，点击可打开新版本下载。
- 本地服务 `/api/health` 会返回当前版本，`/api/update` 会返回最新版本、安装包和免安装版资产。
- 侧边栏顶部按钮位置更稳定，折叠/展开时不会挤压品牌区。

## Windows Desktop

推荐下载 `Dev-Cockpit-Setup-0.1.3-win-x64.exe`。它是标准安装向导，适合日常使用；已安装旧版本时会直接覆盖升级。

如果只想临时试用，可以下载 `Dev-Cockpit-0.1.3-win-x64.exe`。portable 用户需要关闭旧 exe 后手动替换新文件。

当前产物仍未代码签名，Windows 可能提示未知发布者。

## Verification

- `pnpm --filter @local-dev-cockpit/server test`
- `pnpm --filter @local-dev-cockpit/web typecheck`
- `pnpm release:check`
- `pnpm --filter @local-dev-cockpit/desktop dist:win`
- 启动 portable exe 后验证 `/api/health` 返回 `0.1.3`
