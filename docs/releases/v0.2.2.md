# Dev Cockpit 0.2.2

本版修复 0.2.1 的发布校验问题：CLI 运行时版本号仍显示为旧版本。

## Fixes

- `local-dev-cockpit --version` 现在从包自身 `package.json` 读取版本，避免后续发版漏改硬编码常量。
- `/api/health` 的默认版本也从 server 包版本读取；CLI 和桌面版仍可显式传入版本。
- 修正资源导入空输入提示的中文编码。

## Verification

- `pnpm release:check`
- `pnpm --filter @local-dev-cockpit/desktop dist:win`
