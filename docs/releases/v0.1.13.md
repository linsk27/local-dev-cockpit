# Dev Cockpit 0.1.13

这版是 UI 可用性和架构稳定版，重点修复项目筛选遮挡、优化 Cream 奶油主题，并把后续继续迭代容易失控的代码区域拆清楚。

## Highlights

- 项目列表新增稳定筛选视图：全部、在线、标准可运行、可尝试运行、需处理、未识别。
- 修复筛选 chip 在窄列表宽度下被遮挡、挤压和横向溢出的问题。
- 重做 Cream 奶油主题：奶白浅咖底色、宽圆角面板、磨砂半透明、低饱和马卡龙按钮和柔和浮雕控件。
- 资源占用卡片改为工作台自身占用说明，失败时保留最后一次有效数据并标记数据稍旧。
- 拆分项目页 CSS、Server 路由、端口状态服务、Python runtime 和失败摘要规则，降低后续新增模块的维护风险。
- 保持现有核心接口不变：CLI、HTTP API、Electron 启动方式、项目扫描、命令运行、日志、端口、AI 上下文都兼容旧版本。

## Verification

- `pnpm --filter @local-dev-cockpit/web test`
- `pnpm --filter @local-dev-cockpit/web typecheck`
- `pnpm release:check`
- `git diff --check`
- 浏览器检查项目页 Cream 主题：筛选区完整显示、无横向溢出、控制台无错误。
