# Dev Cockpit 0.1.0

这是第一个可公开体验的 MVP 版本，重点是把本地多个开发项目的运行状态、命令、日志、端口、Git 信息和 AI 上下文放到一个桌面工作台里。

## 主要能力

- Vue 3 Dashboard：通过 `npx local-dev-cockpit` 启动本地 Web 面板。
- Windows 桌面版：提供 Electron portable exe，可以直接下载体验。
- 项目总览：扫描指定工作目录，展示项目路径、技术栈、Git 分支、未提交数量、端口和运行状态。
- 命令与日志：在面板里启动/停止常见开发命令，并查看对应日志。
- 端口检测：识别常见本地开发端口，辅助判断服务是否已经运行或发生冲突。
- AI 上下文：生成并复制当前项目摘要，也可以写入 `PROJECT_CONTEXT.md` / `AGENTS.md`。
- 低开销轮询：按当前选择的工作目录刷新项目状态，减少不必要扫描。

## Windows 桌面版

下载 `Dev-Cockpit-0.1.0-win-x64.exe` 后可直接运行。当前是未签名 portable 版本，Windows 可能提示未知发布者，这是正常现象。

## 验证记录

- `pnpm release:check`
- `pnpm --filter @local-dev-cockpit/desktop dist:win`
- 启动 portable exe 后验证 `/api/health` 正常返回

## 已知限制

- 当前桌面版还没有代码签名。
- 端口检测依赖操作系统返回的信息，极少数情况下 Windows 端口表可能短暂滞后。
- 第一版不接入云同步、账号系统和团队协作。
