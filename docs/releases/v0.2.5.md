# Dev Cockpit 0.2.5

This release scales the Resource Radar for larger local libraries, tightens the macOS-style workbench layout, and improves native Windows launch actions.

## Highlights

- Resource Radar now supports indexed filtering and virtualized lists for large local JSON libraries while keeping small libraries in a compact Finder-style list.
- The resource nebula summarizes larger libraries by category and representative resources instead of rendering every item at once.
- Resource import now reports added, skipped, and failed counts with stronger duplicate detection across normalized URLs, GitHub repositories, and title-summary fingerprints.
- The resources and projects pages now use a denser workbench layout with fixed-height panes and internal scrolling.
- Windows open-folder and open-editor actions now validate native launches more carefully and handle VS Code command resolution through App Paths and PATH shims.
- Resource AI parsing keeps local fallback cards when an AI request times out, and the context handoff action has clearer detail-panel placement.
