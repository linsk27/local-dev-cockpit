# Dev Cockpit 0.2.3

本版本继续收口项目控制台和资源雷达，重点是资源导入质量、资源库迁移能力、端口冲突操作入口，以及桌面版文档截图同步。

## Highlights

- 资源雷达支持导出 / 导入 JSON，可在多台电脑或不同应用之间迁移同一批资源。
- 资源导入会校验字段、规范化大类 / 小类，并按来源 URL、标题摘要和 id 跳过重复资源。
- 资源卡片列表、详情页和星云图继续收敛为更紧凑的展示方式，减少冗余动作。
- 项目页补强端口冲突和外部在线状态的操作入口，能更清楚地打开或停止可归属端口。
- README 更新资源雷达、AI 配置和截图，文档与当前界面保持一致。
