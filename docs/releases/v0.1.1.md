# Dev Cockpit 0.1.1

这是一个可靠性补丁，重点是让别人下载后更容易跑起真实项目，而不是只适配作者本机环境。

## 主要变化

- 新增运行环境诊断：项目概览会显示每条命令是否具备运行条件。
- Python 启动前自动识别 `.venv`、`venv`、`.env`、`env`、`.conda`、Conda `environment.yml`。
- Java 支持 Maven、Gradle、Spring Boot，并优先使用项目自带的 `mvnw` / `gradlew`。
- 新增 PHP/Laravel、Ruby/Rails/Rack、.NET 项目识别。
- CLI `doctor` 扩展为本机运行时检查，并支持 `local-dev-cockpit doctor <projectPath>` 查看项目命令环境。
- 文档同步说明运行环境解析策略和已知边界。

## Windows Desktop

下载 `Dev-Cockpit-0.1.1-win-x64.exe` 后可直接运行。当前仍是未签名 portable 版本，Windows 可能提示未知发布者。

## 验证记录

- `pnpm release:check`
- `node packages\cli\dist\index.js doctor D:\个人\langchain-ai-langchain\backend`
- `pnpm --filter @local-dev-cockpit/desktop dist:win`
- 启动 portable exe 后验证 `/api/health` 正常返回

## 已知限制

- Dev Cockpit 只选择已有环境，不自动创建 venv、Conda env，也不自动安装依赖。
- PHP/Ruby/.NET/Java 等运行时需要用户机器已经安装，或项目自带 wrapper。
- 桌面版尚未代码签名。
