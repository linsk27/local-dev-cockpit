# Dev Cockpit 0.2.1

本版重点补齐资源雷达，并继续修复本地项目控制台的端口与启动体验。

## Highlights

- 新增资源雷达：收集 GitHub 仓库、Demo、工具、教程、Prompt、MCP、Workflow 和 AI skills 线索。
- 资源导入改为“解析预览 -> 确认入库”，避免误点后直接写入资源库。
- 支持可选 AI 配置：可使用 OpenAI-compatible 端点辅助生成结构化资源卡片。
- 资源卡片新增动态大类 / 小类、标签、摘要、置信度、来源信息和详情页。
- 新增 Three.js 星云图视图，用于按资源类别浏览和聚焦资源。
- 优化项目启动前的端口守卫和外部在线状态提示。
- README 更新了中文说明、使用流程和页面截图。
